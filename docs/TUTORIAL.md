# Чекунец Банк — полное руководство

Пошагово: как запустить банк, вывести его в интернет, включить настоящие
переводы между людьми, получить права администратора и пользоваться всеми
разделами. Читать можно подряд — шаги идут в том порядке, в котором их нужно
выполнять.

---

## 1. Что вообще происходит

Банк состоит из двух частей:

* **Сайт** — папка репозитория (`index.html`, `assets/`). Обычные HTML, CSS и
  JavaScript, никакой сборки. Его раздаёт GitHub Pages.
* **Сервер** — база данных с логикой банка (`supabase/schema.sql`). В ней лежат
  клиенты, счета, операции, кредиты и магазин; она же считает переводы.

Без сервера сайт работает **автономно**: счёт хранится в браузере посетителя,
и перевести деньги другому человеку нельзя. С сервером банк становится общим:
двое людей с разных телефонов реально переводят друг другу чекурубли.

Валюта банка — **чекурубль**, значок ₡.

---

## 2. Быстрый запуск на своём компьютере

1. Скачайте репозиторий (`Code → Download ZIP`) и распакуйте.
2. Откройте `index.html` двойным щелчком.
3. Зарегистрируйтесь — банк сразу выпустит карту.

Это автономный режим: данные лежат в вашем браузере. Для проверки интерфейса
этого достаточно.

---

## 3. Публикация сайта на GitHub Pages

1. Откройте репозиторий на GitHub → **Settings** → в левом меню **Pages**.
2. В блоке **Build and deployment** в поле **Source** выберите **GitHub Actions**.
   Это единственный ручной шаг, который нельзя сделать из кода: пока Pages не
   включён, деплой падает с ошибкой `Get Pages site failed / Not Found`.
3. Вкладка **Actions** → workflow **Deploy Чекунец Банк to GitHub Pages** →
   **Run workflow** (или просто сделайте любой коммит).
4. Через минуту сайт будет по адресу вида
   `https://ВАШ-ЛОГИН.github.io/chekunec_bank/`.

Адрес виден в конце лога деплоя и в **Settings → Pages**.

---

## 4. Включаем настоящие переводы (сервер)

GitHub Pages умеет отдавать только файлы, поэтому общая база живёт отдельно —
в бесплатном проекте Supabase. Займёт около пяти минут.

### 4.1. Создать проект

1. Зайдите на **supabase.com** → **Start your project** → войдите через GitHub.
2. **New project**.
   * **Name** — например `chekunec-bank`.
   * **Database Password** — придумайте и сохраните (пригодится только для
     прямого доступа к базе, в сайте он не используется).
   * **Region** — ближайший к вам.
3. Нажмите **Create new project** и подождите 1–2 минуты, пока проект
   поднимается.

### 4.2. Залить схему банка

1. В левом меню проекта — **SQL Editor** → **New query**.
2. Откройте файл [`supabase/schema.sql`](../supabase/schema.sql) из репозитория,
   скопируйте **целиком** и вставьте в редактор.
3. Нажмите **Run** (или Ctrl+Enter). Внизу должно появиться `Success. No rows returned`.

Схема создаёт таблицы (клиенты, сессии, операции, кредиты, товары) и все функции
банка: регистрацию, вход, переводы, игры, кредиты, списание просрочек, магазин и
админские операции. Запускать её повторно безопасно — она перезаписывает функции,
не трогая накопленные данные.

### 4.3. Взять адрес и ключ

1. Слева внизу — **Project Settings** (шестерёнка) → **API**.
2. Скопируйте два значения:
   * **Project URL** — вида `https://abcdefgh.supabase.co`;
   * **Project API keys → anon public** — длинная строка.

Ключ `anon public` предназначен для публикации в коде сайта, это нормально.
Ключ `service_role` **никуда вставлять нельзя** — он даёт полный доступ к базе.

### 4.4. Вписать их в сайт

Откройте `assets/config.js` и заполните:

```js
window.CB_CONFIG = {
  url: "https://abcdefgh.supabase.co",
  anonKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
};
```

Закоммитьте и запушьте — GitHub Pages пересоберётся сам. Теперь у всех
посетителей сайта общий банк.

Проверка: на экране входа под формой должно быть написано
**«● Онлайн-режим: счета общие для всех»**, а в шапке кабинета — значок `online`.

> Не хотите править код ради теста? На экране входа есть кнопка
> **⚙︎ Настройка сервера** — вставьте туда адрес и ключ, они сохранятся только
> в вашем браузере. Для общего сайта всё равно нужен `config.js`.

### 4.5. Проверить переводы

1. Откройте сайт на двух устройствах (или в обычном окне и в приватном).
2. Зарегистрируйте двух разных клиентов.
3. На первом: **Главная → Перевести**, введите телефон второго, сумму, отправьте.
4. На втором обновите страницу (кнопка ⟳ в шапке) — деньги на месте, в истории
   появилась операция.

## 5. Права администратора

Администратором становится **первый зарегистрированный клиент с именем
«Сергей» и фамилией «Крюков»**. Регистрируйтесь на свежей базе первым — и в
профиле появится корона 👑, а в нижнем меню — вкладка **Админ**.

Регистр не важен (`сергей крюков` тоже подойдёт — банк сам приводит имя к виду
`Сергей Крюков`), но написание должно совпадать буква в букву. Второй такой же
регистрации админка уже не достанется.

**Если админ не выдался** (например, кто-то зарегистрировался раньше) —
назначьте вручную. Supabase → **SQL Editor**:

```sql
update cb_users set role = 'admin' where phone = '+79161112233';
```

Телефон подставьте свой, в формате `+7XXXXXXXXXX`. После этого перезайдите в
кабинет.

### Роли

| Роль | Что может |
|---|---|
| **Клиент** | обычный кабинет: переводы, игры, кредиты, магазин |
| **Разработчик** 🛠 | всё то же + смотрит аналитику, список людей и ленту операций (ничего не меняет) |
| **Администратор** 👑 | всё вышеперечисленное + выдаёт чекурубли, назначает роли, блокирует счета |

Роль выдаётся из админ-панели: **Люди → у нужного человека кнопка «🎖 Роль»**.
Администратор не может понизить сам себя и не может заблокировать другого
администратора — это защита от случайной потери доступа.

## 6. Админ-панель

Вкладка **Админ** (видна только сотрудникам банка) состоит из трёх разделов.

### Аналитика

* клиенты: всего, заблокированные, администраторы, разработчики, должники;
* деньги: сколько чекурублей на счетах, оборот за сутки, сумма переводов,
  сколько банк выдал вручную, сколько потрачено в магазине;
* кредиты: активные, просроченные, общая выданная сумма;
* игры: сколько сыграно и общий итог казино (плюс — банк в выигрыше);
* столбики регистраций за последние 7 дней и топ-5 богатейших.

### Люди

Список всех зарегистрированных, свежие сверху. Поиск работает по имени,
телефону, номеру карты и почте. По каждому видно: баланс, почту, карту, дату
регистрации, количество операций и активных кредитов, статус.

Кнопки под карточкой (только для администратора):

* **🏛 Начислить** — выдать чекурубли. Отрицательная сумма списывает. Причина
  попадает в историю клиента и в ленту банка.
* **🎖 Роль** — сделать клиентом, разработчиком или администратором.
* **🚫 Заблокировать** — с указанием причины. Заблокированный не может войти,
  а его сессии обрываются немедленно; переводы ему тоже не проходят. Кнопка
  превращается в **🔓 Разблокировать**.
* **💸 Перевести** — обычный перевод со своего счёта.

### Лента

Последние 40 операций всего банка: кто, что, на какую сумму и когда.

## 7. Куда тратить чекурубли — магазин

Вкладка **Магазин**.

| Товар | Цена | Что даёт |
|---|---|---|
| Скин «Неон» | 2 500 ₡ | розово-голубая карта |
| Скин «Лёд» | 3 000 ₡ | ледяная карта |
| Скин «Багровая» | 3 500 ₡ | тёмно-красная карта |
| Скин «Карбон» | 4 000 ₡ | матовая чёрная карта |
| Скин «Золотая» | 9 000 ₡ | самая дорогая карта банка |
| Титул «Везунчик» | 1 500 ₡ | подпись у имени |
| Титул «VIP-клиент» | 4 000 ₡ | подпись у имени |
| Титул «Магнат» | 12 000 ₡ | подпись у имени |
| Страховка от просрочки | 1 200 ₡ | один раз отменяет штраф 25 % |
| Двойной бонус, 7 дней | 1 800 ₡ | бонус дня 100 ₡ вместо 50 ₡ |
| Повышенный кредитный лимит | 15 000 ₡ | кредиты до 150 000 ₡ навсегда |

Купленный скин надевается нажатием на него в разделе «Оформление карты»,
титул — в разделе «Титулы», значок — в «Значок вместо инициалов». Всё это
меняется сколько угодно раз и видно другим в рейтинге.

Заработать на покупки можно в разделе **Игры**, получать **бонус дня** на
главной или попросить начисление у администратора.

## 8. Кредиты и просрочка

* Сумма: от 100 до 50 000 ₡ (150 000 ₡ с купленным повышенным лимитом).
* Сроки и ставки: 1 день — 5 %, 3 дня — 10 %, 7 дней — 18 %, 30 дней — 35 %.
* Одновременно не больше трёх активных кредитов.
* Погашать можно частями в любой момент.

**Если не вернуть вовремя:** банк сам, при первом же открытии кабинета после
наступления срока, списывает весь остаток долга и штраф 25 % от него. Баланс
при этом уходит в минус — это нормальное состояние счёта, из которого нужно
выбираться заработком. Купленная заранее страховка отменяет штраф (но не сам
долг) и расходуется.

---

## 9. Игры

Без риска:

* **Смена в банке** — 10 секунд кликов, 0,6 ₡ за клик (не больше 120 кликов),
  перерыв 2 минуты.
* **Викторина** — 5 вопросов, по 15 ₡ за верный ответ, перерыв 5 минут.

Со ставкой:

* **Орёл или решка** — ×1.95 при угадывании.
* **Кости против банка** — ваши два кубика против банковских: больше — ×2,
  ничья — возврат ставки.
* **Колесо фортуны** — сектора ×0, ×0.5, ×1.5, ×2, ×3, ×5, ×10.
* **Краш** — множитель растёт, нужно успеть забрать до взрыва.

## 10. Что делать, если что-то не работает

| Симптом | Причина и лечение |
|---|---|
| На экране входа «◐ Автономный режим» | не заполнен `assets/config.js` либо изменения ещё не задеплоились. Проверьте вкладку Actions |
| «Нет связи с сервером банка» | неверный адрес проекта или проект в Supabase приостановлен (бесплатные проекты засыпают при простое — зайдите в панель Supabase и разбудите) |
| `Could not find the function public.cb_login` | схема не выполнена или выполнена не целиком. Откройте SQL Editor и запустите `supabase/schema.sql` заново |
| «Сессия истекла, войдите заново» | токен устарел или счёт заблокировали. Войдите снова |
| «Клиент Чекунец Банка не найден» | получатель не зарегистрирован в этом банке либо номер введён с ошибкой |
| Деплой падает: `Get Pages site failed` | не включён GitHub Pages — см. шаг 3 |
| Не досталась админка | назначьте роль вручную запросом из раздела 5 |
| Хочу начать всё с чистого листа | в SQL Editor: `truncate cb_users cascade;` — удалит всех клиентов, их операции и кредиты |

## 11. Полезные запросы для администратора

```sql
-- сколько всего чекурублей в банке
select sum(balance) from cb_users;

-- десять самых богатых
select first_name, last_name, balance from cb_users order by balance desc limit 10;

-- все просроченные кредиты
select u.first_name, u.last_name, c.amount, c.total, c.due_at
from cb_credits c join cb_users u on u.id = c.user_id
where c.status = 'overdue';

-- выдать клиенту 5000 ₡ вручную (лучше делать из админ-панели)
select cb_admin_issue(
  (select token::text from cb_sessions s join cb_users u on u.id = s.user_id
    where u.role = 'admin' order by s.last_seen desc limit 1),
  '+79995554433', 5000, 'компенсация');

-- разблокировать всех
update cb_users set blocked = false, blocked_reason = '';
```

## 12. Про безопасность честно

* Таблицы закрыты Row Level Security **без единой политики**: публичный ключ не
  даёт прямого доступа к данным. Сайт работает только через функции, каждая из
  которых проверяет токен сессии и права.
* PIN-код не покидает браузер — на сервер уходит только его SHA-256-хеш.
* Результаты игр считает браузер; сервер лишь ограничивает размер ставки и
  максимальный выигрыш. При желании подготовленный человек может накрутить себе
  чекурубли — для игровой валюты это допустимо, для настоящих денег так делать
  нельзя.
* Чекурубль не имеет ценности и ни к чему не привязан. Это развлекательный
  проект, а не финансовая организация.
