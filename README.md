# Чекунец Банк

Онлайн-банк со своей валютой — **чекурубль**, названной в честь чекушки.
Банк шуточный: никаких реальных платежей и настоящих денег здесь нет. Работает как обычный сайт
на GitHub Pages: регистрация с выпуском именной карты, переводы другим клиентам,
игры, магазин, кредиты с просрочкой и админ-панель.

**Подробное руководство со всеми шагами — [docs/TUTORIAL.md](docs/TUTORIAL.md)**

## Разделы

| Раздел | Возможности |
|---|---|
| **Регистрация** | Имя и фамилия, телефон с проверкой формата `+7`, почта, PIN. Банк выпускает карту: уникальный номер с контрольной цифрой Луна, держатель латиницей, срок действия +5 лет, CVV, 20-значный счёт и бонус 500 чекурублей |
| **Главная** | Карта, счёт, баланс, перевод по телефону / номеру карты / счёта, бонус дня, рейтинг клиентов, последние операции |
| **История** | Все операции с фильтрами и поиском, детали каждой |
| **Игры** | 22 игры, часть на холсте с анимацией. Без ставки: кликер, викторина, «Ревизия склада» на память, «Счётная касса» на устный счёт, «Инкассатор» на реакцию, «Сортировка купюр». Со ставкой: монетка, кости, колесо фортуны, «Краш», «Три стопки», «Погреб», барабаны до ×20, «Башня», «Больше или меньше», рулетка, гонка чекушек, камень-ножницы-бумага, двадцать одно |
| **Магазин** | 22 товара: ящики чекушек со случайным призом и редким оформлением, шесть оформлений карты, пять титулов, гравировка и перевыпуск карты, цвет значка, страховка от просрочки, кредитные каникулы, двойной бонус, повышенный лимит, кэшбек с проигрышей, автопогашение кредита, надбавка к ставке вкладов |
| **Вклады** | 500 чекурублей и выше на 1/3/7/30 дней под 2/5/9/20 %. Выплата приходит сама в день закрытия, досрочно — без процентов |
| **Кредиты** | 100–50 000 чекурублей (150 000 с апгрейдом) на 1/3/7/30 дней под 5/10/18/35 %. Не вернул вовремя — списание остатка и штраф 25 %, баланс уходит в минус |
| **Опции** | Тема, скрытие баланса, уведомления, звуки, видимость в рейтинге, смена PIN, выгрузка данных, удаление счёта |
| **Профиль** | ФИО и написание латиницей, телефон, необязательная почта, реквизиты, статус и титул, 12 достижений, статистика |
| **Админ** | Аналитика банка, список всех зарегистрированных с поиском, выдача чекурублей, назначение ролей, блокировка счетов, лента операций |

Администратором становится первый зарегистрированный **Сергей Крюков**;
роли **разработчик** (только просмотр аналитики и клиентов) и **администратор**
дальше выдаются из панели.

## Что куда вставлять — коротко

| Что | Куда |
|---|---|
| `supabase/schema.sql` | Supabase → SQL Editor → Run |
| Project URL и anon-ключ из Supabase → Settings → API | `assets/config.js` |
| Ничего | GitHub → Settings → Pages → Source: **GitHub Actions** |

Однофайловая сборка: `node build.js` → `dist/chekunec-bank.html`, открывается
двойным щелчком и заливается на любой хостинг как один файл.

## Запуск

1. **Локально** — открыть `index.html`, банк работает автономно (данные в браузере).
2. **В интернете** — Settings → Pages → Source: **GitHub Actions**, дальше сайт
   собирается сам при каждом пуше.
3. **Общие переводы между людьми** — завести бесплатную базу, выполнить
   `supabase/schema.sql`, вписать адрес и ключ в `assets/config.js`.
   Всё по шагам: [docs/TUTORIAL.md](docs/TUTORIAL.md).

## Структура

```
index.html            экраны: вход, выдача карты, кабинет
assets/styles.css     оформление, тёмная и светлая темы
assets/config.js      адрес и ключ сервера
assets/api.js         работа с данными: сервер или локальное хранилище
assets/app.js         интерфейс всех разделов
supabase/schema.sql   таблицы, функции банка, права
docs/TUTORIAL.md      подробное руководство
```

Сборка не нужна: чистый HTML, CSS и JavaScript.
