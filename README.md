# 🏦 Чекунец Банк

Онлайн-банк с собственной валютой — **чекурубль (₡)**. Работает как обычный сайт
на GitHub Pages: регистрация, выпуск именной карты, переводы другим клиентам по
номеру телефона или карты, игры на чекурубли, кредиты с реальными сроками и
просрочкой, настройки и профиль.

## Что внутри

| Раздел | Возможности |
|---|---|
| **Регистрация** | Имя и фамилия, телефон с проверкой формата `+7`, почта, PIN-код. По завершении банк выпускает карту: уникальный 16-значный номер (проходит проверку Луна), держатель латиницей, срок действия +5 лет, CVV, 20-значный номер счёта и приветственный бонус 500 ₡ |
| **Главная** | Карта, номер счёта, баланс в чекурублях, перевод другому клиенту по телефону / номеру карты / счёта, бонус дня, рейтинг клиентов, последние операции |
| **История** | Все операции с фильтрами (переводы, игры, кредиты, бонусы), поиск, статистика и детали каждой операции |
| **Игры** | Без риска: «Смена в банке» (кликер) и викторина. Со ставкой: монетка ×1.95, кости против банка ×2, колесо фортуны ×0…×10, «Краш» — забрать до взрыва |
| **Кредиты** | Суммы 100–50 000 ₡, сроки 1/3/7/30 дней под 5/10/18/35 %. Досрочное и частичное погашение. **Не вернул вовремя — банк списывает весь остаток и штраф 25 %, баланс уходит в минус** |
| **Настройки** | Тема, скрытие баланса, уведомления, звуки, видимость в рейтинге, смена PIN, выгрузка данных, выход, удаление счёта |
| **Профиль** | ФИО и написание латиницей, телефон, почта, реквизиты карты и счёта, дата открытия счёта, статистика, изменение контактов |

## Как запустить онлайн (GitHub Pages)

1. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. Запушьте ветку — workflow `.github/workflows/pages.yml` опубликует сайт.
3. Адрес будет вида `https://<логин>.github.io/chekunec_bank/`.

Сайт откроется сразу, но пока в **демо-режиме**: данные лежат в браузере
посетителя, переводы между разными людьми невозможны. Чтобы банк стал общим —
подключите бесплатную базу.

## Как включить настоящие переводы между людьми (5 минут)

GitHub Pages отдаёт только статику, поэтому общий счёт-регистр живёт в бесплатном
проекте [Supabase](https://supabase.com).

1. Создайте проект на supabase.com (Free plan).
2. **SQL Editor → New query** → вставьте целиком файл [`supabase/schema.sql`](supabase/schema.sql) → **Run**.
   Так создаются таблицы и вся банковская логика: регистрация, вход, переводы,
   игры, кредиты, списание просрочек.
3. **Settings → API** скопируйте `Project URL` и ключ `anon public`.
4. Впишите их в [`assets/config.js`](assets/config.js) и запушьте:

   ```js
   window.CB_CONFIG = {
     url: "https://xxxxxxxx.supabase.co",
     anonKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6..."
   };
   ```

5. Готово: у всех посетителей сайта общий банк. Открыв сайт на двух телефонах и
   зарегистрировав двух клиентов, можно перевести чекурубли с одного на другой —
   деньги дойдут по-настоящему.

Проверить подключение можно и без правки кода: на экране входа — «⚙︎ Настройка
сервера», вставить URL и ключ (сохранится только в этом браузере).

### Про безопасность

Таблицы закрыты Row Level Security **без единой политики**, поэтому анонимный
ключ не даёт прямого доступа к данным: клиент ходит только через функции
`SECURITY DEFINER`, каждая из которых проверяет токен сессии. PIN-код никогда не
покидает браузер — на сервер уходит только SHA-256-хеш. Это учебно-развлекательный
проект: чекурубль не имеет ценности, а результаты игр считает клиент (сервер лишь
ограничивает ставку и максимальный выигрыш), так что «взломать» баланс при желании
можно — реальные деньги так защищать нельзя.

## Структура

```
index.html            экраны: вход/регистрация, выдача карты, личный кабинет
assets/styles.css     оформление, тёмная и светлая темы
assets/config.js      адрес и ключ сервера (пусто = демо-режим)
assets/api.js         два адаптера данных: Supabase (онлайн) и localStorage (демо)
assets/app.js         весь интерфейс: главная, история, игры, кредиты, настройки, профиль
supabase/schema.sql   таблицы, RPC-функции, права
```

Сборка не нужна: чистый HTML/CSS/JS, файл `index.html` открывается и локально.
